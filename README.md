Multi-Cloud Secure Infrastructure

Project Overview

This project focuses on implementing and understanding secure cloud infrastructure using AWS and multi-cloud security concepts.

Technologies Used

* Amazon Web Services (AWS)
* AWS EC2
* Amazon S3
* Ubuntu Linux
* Terraform
* AWS CLI
* Docker
* AWS CloudTrail
* Splunk Enterprise
* Kali Linux
* Nmap

Implementation

* AWS account setup
* Ubuntu EC2 instance deployment
* Docker installation and testing
* Terraform installation and configuration
* AWS CLI configuration
* Amazon S3 bucket deployment using Terraform
* AWS CloudTrail monitoring
* CloudTrail log export and Splunk analysis
* Basic network reconnaissance using Nmap

Multi-Cloud Concepts

AWS was used for practical implementation. Microsoft Azure was studied at a conceptual level.

Project Purpose

To understand cloud infrastructure deployment, automation, security monitoring and log analysis.
